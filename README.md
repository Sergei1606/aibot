# AI News Bot for Telegram

AIBot — это автоматизированный конвейер (pipeline), который собирает новости из RSS-каналов и Telegram, фильтрует их по ключевым словам, использует OpenAI для создания кратких постов (саммари) и автоматически публикует их в заданный Telegram-канал.

## Архитектура и Технологии
- **FastAPI** — веб-интерфейс для мониторинга и REST API.
- **Celery + Redis** — асинхронные фоновые задачи (парсер, генерация, публикация).
- **PostgreSQL** — хранение новостей, сгенерированных постов и источников (SQLAlchemy ORM + asyncpg).
- **Docker Compose** — полная оркестрация всех сервисов.
- **OpenAI API (GPT-3.5-Turbo)** — генерация выжимок из исходного текста новостей.

## Как запустить

1. Клонируйте репозиторий и создайте файл `.env` в корне проекта (см. `app/config.py` для списка переменных).
2. Выполните команду для сборки и запуска контейнеров:
```bash
docker compose up --build
```
3. Веб-интерфейс будет доступен по адресу: `http://localhost:8000`.

## Структура проекта
- `app/main.py` — Главное приложение FastAPI.
- `app/tasks.py` — Логика воркеров Celery (парсинг, генерация, публикация).
- `app/ai/` — Модуль интеграции с OpenAI.
- `app/news_parser/` — Парсеры сайтов и Telegram-каналов (RSS / Telethon).
- `app/telegram/` — Бот для финальной публикации постов в канал (Aiogram / Telethon).
